# dma2box

Клиент vmess/vless/hysteria2/trojan/SS на базе sing-box, GTK4 + AppIndicator.

## Структура исходников

Исходники разделены по архитектурам — у каждой свой полный набор кода,
свой интерфейс и свои точки входа в сборку:

```
arch/
├── x86_64/              # x86-64 (amd64) — основная линия разработки, здесь будет новый интерфейс
├── x86/                 # 32-bit x86 (i386…i686)
└── arm/
    ├── armv7/           # ARMv7 (armv7l, armhf)
    ├── aarch32/         # AArch32 (32-битный пользовательский режим ARMv8, armv8l)
    └── aarch64/         # AArch64 / ARM64
```

В корне остались только тонкие врапперы (`build.sh`, `install.sh`,
`check_theme.py`, `scripts/build_packages.sh`), которые по `uname -m`
выбирают нужное дерево в `arch/`, а также общие `.github/` и `.gitignore`.

Подробная документация по приложению — в `arch/x86_64/README.md`.
Остальные папки — базовые снимки исходников, готовые к независимой адаптации.

## Сборка и установка

```bash
./build.sh                         # собрать под архитектуру текущей машины
./install.sh                       # установить в ~/.local
sudo ./install.sh --system         # системная установка в /usr
python3 check_theme.py             # проверка темы
```

Врапперы автоматически вызывают соответствующие скрипты из `arch/<цель>/`.
Для кросс-сборки вызывайте нужный скрипт напрямую, например
`arch/arm/aarch64/build.sh`.

## Состояние

- `arch/x86_64/` — рабочее дерево: режим «Роутер» в трее, исправленный импорт
  vmess через `dbus`/`GFile`, подписи режимов вынесены в `state.py`.
- `arch/x86/`, `arch/arm/*` — базовые снимки, адаптируются отдельно; ядра и
  интерфейсы выбираются внутри каждого дерева.

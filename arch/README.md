# Исходники по архитектурам

Каждая папка — автономное дерево исходников: `dma2box/`, `data/`, `tests/`,
`scripts/`, `build.sh`, `install.sh`, `check_theme.py`, `LICENSE`, `README.md`.

| Каталог | `uname -m` | Примечание |
| --- | --- | --- |
| `x86_64/` | `x86_64`, `amd64` | основная разработка; здесь планируется новый интерфейс |
| `x86/` | `i386`…`i686` | 32-bit x86 |
| `arm/armv7/` | `armv7l`, `armv6l` | ARMv7 / armhf |
| `arm/aarch32/` | `armv8l`, `aarch32` | 32-bit userspace на ARMv8 |
| `arm/aarch64/` | `aarch64`, `arm64` | AArch64 / ARM64 |

`detect.sh` используется корневыми врапперами для выбора каталога под текущую
машину. Кросс-сборка — прямым вызовом скрипта внутри нужного каталога.

# x86 (32-bit)

Дерево исходников dma2box для 32-битных x86-машин (`i386`…`i686`).

Синхронизирован с `arch/x86_64/`. Интерфейс, зависимости и ядро
должны адаптироваться под 32-битную архитектуру внутри этого каталога.

Особенности общего кода x86/x86-64: прямоугольный UI (резкие углы), 4 режима
(прокси / системный / ВПН / роутер с NAT), health-check с автопереключением,
правила маршрутизации и geo rule-sets, xhttp-профили через Xray-core.

Сборка: `./build.sh`, установка: `./install.sh` (или из корня — врапперы сами
выберут это дерево на соответствующей машине).
